Hospital Management System – Storyboard

1. Project Overview

The Hospital Management System is designed to manage hospital activities digitally. It helps manage patient registration, doctor information, appointments, medical records and billing.

2. Objectives

- Simplify patient registration.
- Manage doctor information.
- Schedule patient appointments.
- Maintain medical records.
- Generate patient bills.
- Manage hospital activities.

3. Project Modules

1. Patient Registration
2. Doctor Management
3. Appointment Management
4. Medical Records
5. Billing Management
6. Admin Management

4. Project Progress

The project progress is tracked using GitHub Projects.

- Todo: Tasks not yet started.
- In Progress: Tasks currently being developed.
- Done: Tasks successfully completed.

5. Testing

Test cases are prepared for all the main modules to verify system functionality.

6. Tools Used

- GitHub
- GitHub Projects
- Markdown

7. Conclusion

The storyboard helps organize and track the development progress of the Hospital Management System. Test cases help verify the functionality and reliability of the system.
